## 🌐 API Endpoints (3 NEW)

### ✅ Endpoint 1: SUBMIT TASK
```
POST /api/v1/task-submission/:task_id

Input:  Multipart Form-Data
  • notes (required): Task completion notes
  • attachments (optional): Files (max 50MB each)
  • attachment_notes (optional): Notes for each file

Output: 201 Created
  • submission record with ID
  • attachment metadata (file_name, file_path, file_size)
  • empty reviews array
```

### ✅ Endpoint 2: GET SUBMISSIONS
```
GET /api/v1/task-submission/:task_id

Input:  None (task_id in URL)

Output: 200 OK
  • Array of submissions
  • Each with attachments array
  • Each with reviews array (from all reviewers)
```

### ✅ Endpoint 3: REVIEW SUBMISSION
```
POST /api/v1/task-submission/:submission_id/review

Input:  JSON
  • status: "in_progress" | "completed"
  • review_notes: Feedback text

Output: 201 Created
  • review record with:
    - reviewer_id, reviewer_role
    - status, review_notes
    - reviewed_at timestamp
```

## 🔄 COMPLETE WORKFLOW

```
STEP 1: PENTESTER SUBMITS
   POST /api/v1/task-submission/task-123
   └─ Response: 201 Created (submission_id)

STEP 2: ADMIN VIEWS
   GET /api/v1/task-submission/task-123
   └─ Response: 200 OK (submission + empty reviews)

STEP 3: ADMIN REVIEWS
   POST /api/v1/task-submission/submission-123/review
   ├─ status: "in_progress"
   └─ Response: 201 Created (review_id_1)

STEP 4: STAKEHOLDER REVIEWS
   POST /api/v1/task-submission/submission-123/review
   ├─ status: "completed"
   └─ Response: 201 Created (review_id_2)

STEP 5: VIEW FINAL STATUS
   GET /api/v1/task-submission/task-123
   └─ Response: 200 OK
      ├─ submission + attachments
      ├─ review_id_1 (admin, in_progress)
      └─ review_id_2 (stakeholder, completed)
```
